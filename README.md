# Desktop Pet - Maid Desktop Buddy
> A Windows desktop pet with unique "eat desktop icons" visual effect.

## 📖 Introduction
**EN**
This is an original pixel maid desktop pet for Windows.
The most distinctive feature: it can "eat" your desktop icons.
> ⚠️ Important: This is only a visual trick. It **WILL NOT DELETE ANY FILES**. Icons can be restored anytime with one click.

Features:
- Eat desktop icons (visual effect only, manual enable)
- Hunger & feeding system
- Focus mode
- Mini game: Catch Light Orbs
- Immersive mischief effects
- Sit on window edges
- One-click restore all hidden icons
- English / Chinese menu language switch
- Built-in entry to visit my game website

**CN**
这是一款Windows原创像素女仆桌宠。
最有特色的功能：可以“吃掉”桌面图标。
> ⚠️ 重要提醒：仅视觉特效，**不会删除任何文件**，可一键恢复所有图标。

功能列表：
- 啃食桌面图标（仅视觉效果，需要手动开启）
- 饥饿 & 喂食系统
- 专注模式
- 内置小游戏：接光点
- 沉浸式捣蛋特效
- 坐到窗口边缘
- 一键恢复所有隐藏图标
- 中英菜单语言切换
- 内置入口跳转至我的游戏站

## 🖥 System Requirement
**EN**: Windows 10 / Windows 11
**CN**: Windows10 / Windows11

## ⚠️ Safety Notice
**EN**
- The pet reads desktop icon position for visual effect, which may trigger false positive alerts from Windows Defender or anti-virus software. It has NO malicious behavior.
- The icon-eating feature is OFF by default. You need manually enable it.
- The program will auto-try to restore icons when closing. You can manually restore icons from right-click menu anytime.

**CN**
- 程序读取桌面图标坐标用于特效展示，可能触发Windows Defender或杀毒软件误报，无任何恶意行为。
- 吃图标功能**默认关闭**，需要用户手动开启。
- 程序关闭时会尝试自动恢复图标，你也可以随时在右键菜单手动一键恢复。
